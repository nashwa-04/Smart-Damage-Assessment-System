## 🎯 نظرة عامة

### فلسفة التصميم

يعتمد النظام على تصميم **Glassmorphism** (الزجاجية الضبابية) مع تدرجات لونية حديثة، مما يوفر:
- مظهر عصري وأنيق
- تجربة بصرية مريحة
- وضوح في القراءة
- انسجام مع هوية النظام

### الألوان الأساسية

| اللون | الكود | الاستخدام |
|-------|-------|-----------|
| **أزرق ندي** | `#3b82f6` | الأزرق الأساسي |
| **بنفسجي** | `#8b5cf6` | التمييز والتدرج |
| **أخضر زمردي** | `#10b981` | النجاح والإكمال |
| **برتقالي** | `#f97316` | التحذيرات |
| **أحمر** | `#ef4444` | الأخطاء والحالات الحرجة |
| **أصفر** | `#eab308` | الانتظار |
| **كهرماني (للأدمن)** | `#f59e0b` | تمييز واجهات المسؤولين |

### الخطوط

- **الخط الأساسي**: Cairo (عربي)
- **الأوزان**: 400 (عادي) → 800 (ثقيل جداً)
- **الاتجاه**: RTL (من اليمين لليسار) للغة العربية

## 🎨 التصميم العام

### الخلفية المتدرجة (Hero Gradient)

```css
background: linear-gradient(135deg, #1e3a5f 0%, #0f172a 50%, #1e1b4b 100%);
```

تدرج من الأزرق الداكن إلى البنفسجي الداكن، يوفر:
- إحساس بالعمق والاحترافية
- تباين ممتاز مع النصوص البيضاء
- خلفية مثالية للبطاقات الزجاجية

### البطاقات الزجاجية (Glass Cards)

```css
background: rgba(255, 255, 255, 0.1);
backdrop-filter: blur(10px);
border: 1px solid rgba(255, 255, 255, 0.2);
border-radius: 24px;
```

**المميزات**:
- شفافية جزئية (10%)
- تأثير ضبابي (blur)
- حواف دائرية ناعمة
- ظلال خفيفة

### نقاط الانكسار (Breakpoints)

| الحجم | العرض | الاستخدام |
|-------|-------|-----------|
| Mobile | < 640px | هاتف صغير |
| SM | ≥ 640px | هاتف كبير |

| LG | ≥ 1024px | لابتوب |

### التكيفات

#### الهاتف (< 768px)
- الشريط الجانبي: يتحول لقائمة منسدلة
- البطاقات: عمود واحد (`grid-cols-1`)
- الجداول: تمرير أفقي (`overflow-x-auto`)

#### التابلت (768px - 1024px)
- البطاقات: عمودان (`grid-cols-2`)
- الشريط الجانبي: يبقى ظاهراً
- الخريطة: ارتفاع 400px

#### سطح المكتب (> 1024px)
- البطاقات: 3-4 أعمدة (`grid-cols-3`, `grid-cols-4`)
- الشريط الجانبي: ثابت
- الخريطة: ارتفاع 600px

```html
<button id="mobileMenuBtn">☰</button>

```

```css
.mobile-menu {
```
